# Global-Olympic-Sports-Performance-Analysis
Data visualization project analyzing Olympic medal records, participation by country, and sports using Tableau Public.
Global Olympic Sports Performance Analysis

Project Overview

Global Olympic Sports Performance Analysis is a data visualization project developed using Tableau Public. It explores Olympic athlete-event records through visualizations of medal categories, participation by National Olympic Committee (NOC), and sports participation.

Objectives

- Analyze the distribution of recorded Olympic medals.
- Compare record counts across National Olympic Committees.
- Identify sports with the highest displayed record counts.
- Present the results through an organized Tableau dashboard and Story.

Dataset

File: "athlete_events.csv"

The dataset provides Olympic athlete-event records used to create the visualizations. Refer to "dataset-source.txt" for the original source and applicable licensing information.

Tools Used

- Tableau Public
- CSV dataset
- GitHub for project documentation and versioned file sharing

Visualizations

1. Olympic Medal Distribution — compares displayed record counts for Gold, Silver, and Bronze.
2. Olympic Participation by Country — compares the record counts for the top ten NOCs shown in the dashboard.
3. Sports Participation — compares record counts across the sports displayed in the chart.

Dashboard and Story

The Tableau dashboard combines the three visualizations into one interface. The Tableau Story presents the analysis in a structured sequence.

Key Observations

- Silver has the highest displayed medal-category count in the current dashboard.
- USA has the highest displayed NOC record count among the ten NOCs shown.
- Athletics has the highest displayed sports record count, followed by Gymnastics and Swimming.

These observations describe the current dashboard view and should be interpreted according to the dataset, filters, and aggregation methods used.

Limitations

The displayed counts may represent records rather than unique athletes, events, or medals. Results depend on the dataset and the Tableau configuration.
